CogniOS

Adaptive OS Intelligence Layer · Linux Userspace · Active Development

Linux workload detection and optimization pipeline running entirely in userspace without kernel modification or elevated root privileges. Collects fine-grained telemetry via psutil and /proc, feeds features into a trained XGBoost classifier to identify workload profiles (compute, memory, I/O, idle) in under 2ms, and flags resource thrashing via an Isolation Forest. Includes an OS flight recorder with commit-log crash-dump capabilities and an offline scheduler simulator for RL evaluation.

How I built a Linux workload classifier without touching the kernel

DRAFT 3 MIN READ SYSTEMS // ML
›

CogniOS needed workload-type awareness without a kernel module. I ended up training an XGBoost classifier on synthetic telemetry — CPU cycles, page faults, I/O patterns — to label running processes as compute-bound, memory-bound, or idle. The key breakthrough was extracting 18 normalized features directly from /proc without root privileges while maintaining sub-2ms inference.

// /proc/[pid]/stat feature extraction window
psutil_snapshot() -> parse_proc_stat() -> 18-dim vector
XGBoost.predict(tensor) -> {COMPUTE: 0.88, MEM: 0.08, IO: 0.04} [1.4ms]
