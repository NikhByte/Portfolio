How I built a Linux workload classifier without touching the kernel

draft in progress
›

CogniOS needed workload-type awareness without a kernel module. I ended up training an XGBoost classifier on synthetic telemetry — CPU cycles, page faults, I/O patterns — to label running processes as compute-bound, memory-bound, or idle. The trick was getting useful features out of /proc without root and keeping inference under 2ms.

XGBoost in userspace: building CogniOS’s ML pipeline from scratch

draft in progress
›

Training a model is one problem. Making it run reliably as a background daemon — handling cold-start, model versioning, telemetry drift, and crash-dump replay — is another. This post covers the full MLflow-tracked pipeline: data gen, labeling heuristics, feature engineering from psutil, model serialization, and how I wired it into CogniOS’s flight recorder.

What hackathons taught me about shipping in 48 hours

draft in progress
›

Three hackathons — Insomniac, Bootup, Cerebras — three completely different constraint profiles. The one consistent lesson: the gap between a working prototype and a presentable product is mostly clarity of scope, not code. I now build the demo path first and work backwards to what the code actually needs to do.
